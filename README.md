# Income Analysis

This project analyzes the income of different people using Python, with a focus on data cleaning and data visualization.

## Overview

The goal of this project is to explore and understand income patterns across a dataset of individuals by:

- cleaning and preparing raw data
- analyzing income distribution and influencing factors
- visualizing insights to make the results easier to interpret

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Process

1. Data collection and loading
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Visualization of income-related trends
5. Interpretation of findings

## Example Analysis Areas

- Income distribution by age group
- Comparison of income across genders or professions
- Relationship between education and income
- Salary trends and outlier detection

## Usage

1. Initialize the project with uv and create the virtual environment:
   ```bash
   uv init
   uv venv
   .venv\Scripts\activate
   ```
2. Install the project dependencies from the requirements file:
   ```bash
   uv add -r requirements.txt
   ```
3. Run the analysis scripts or notebook in the project folder.
4. Review generated charts and cleaned data outputs.

## Conclusion

This project demonstrates how Python can be used to clean, analyze, and present income data effectively through visual storytelling and statistical exploration.
